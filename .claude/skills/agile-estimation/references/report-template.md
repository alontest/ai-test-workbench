# 估点报告模板

输出位置不是已有任务列表时按此模板输出完整报告。写入已有任务列表时，估算写在任务子条目下，不必单独生成此报告，除非用户要求。

### 第五步：输出估点报告

将结果输出为 md 文件，写入位置见 SKILL.md 的「输出」（调用方指定的位置 → 用户指定的路径 → 当前目录的 `./estimation.md`）。

报告必须使用标准 Markdown 格式输出（使用 `#` 标题、`|` 表格、`-` 列表等），
不要使用 ASCII 分隔线或等号装饰。具体格式如下：
