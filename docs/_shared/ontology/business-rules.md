# Business Rules

### BR-C1 密钥只归基座持有
- **对应图谱**：未覆盖
- **规则**：模型提供商配置与密钥只由 `workbench-core` 持有和读取，其他域不得自行直连模型或读取密钥
- **约束对象**：ENT-C2
- **来源 spec**：ai-test-workbench_20261117184149

### BR-C2 会话必须绑定项目
- **对应图谱**：未覆盖
- **规则**：每个会话必须关联一个已存在的项目；不允许创建无项目的会话
- **约束对象**：ENT-C4
- **来源 spec**：ai-test-workbench_20261117184149

### BR-C3 制品按会话隔离
- **对应图谱**：未覆盖
- **规则**：制品路径必须位于 `sessions/<sessionId>/` 下，不得引用其他会话的路径；跨域只按 artifactId 只读引用
- **约束对象**：ENT-C6
- **来源 spec**：ai-test-workbench_20261117184149

### BR-C4 每次模型调用必留记录
- **对应图谱**：未覆盖
- **规则**：凡实际发往提供商的模型调用，无论成功、失败或超时，都必须产生一条 AiCallRecord；在发起请求前被拒绝的调用不产生记录
- **约束对象**：ENT-C7
- **来源 spec**：ai-test-workbench_20261117184149

### BR-C5 单用户无鉴权
- **对应图谱**：未覆盖
- **规则**：本期部署为单用户自托管，不提供登录与鉴权；持久化记录预留 owner 字段但不参与任何校验
- **约束对象**：ENT-C1、ENT-C2、ENT-C4
- **来源 spec**：ai-test-workbench_20261117184149

### BR-C6 密钥加密与全链路掩码
- **对应图谱**：未覆盖
- **规则**：提供商密钥以服务端加密方式存储，加密口令来自环境变量、不写入配置文件；界面、接口响应、日志与提示摘要只允许出现掩码
- **约束对象**：ENT-C2、ENT-C7
- **来源 spec**：ai-test-workbench_20261117184149

### BR-C7 上传边界与同名自动改名
- **对应图谱**：未覆盖
- **规则**：上传仅允许 `.txt .md .markdown .log .json .yaml .yml .csv .sql`，单文件 ≤10MB、单次 ≤10 个；超限拒绝且不落盘；同一会话内同名文件自动改名并保留两份，禁止覆盖
- **约束对象**：ENT-C6
- **来源 spec**：ai-test-workbench_20261117184149

### BR-C8 调用超时与重试
- **对应图谱**：未覆盖
- **规则**：单次模型调用超时 120s；仅网络错误与 5xx 自动重试至多 1 次；最终失败写失败 AiCallRecord 并向调用方抛出可读错误，不自动切换模型
- **约束对象**：ENT-C7
- **来源 spec**：ai-test-workbench_20261117184149

### BR-C9 数据永久保留与级联删除
- **对应图谱**：未覆盖
- **规则**：会话与制品默认永久保留、不做自动过期；仅支持用户手动删除整个会话，删除时级联清理其事件、制品文件与调用记录
- **约束对象**：ENT-C4、ENT-C5、ENT-C6、ENT-C7
- **来源 spec**：ai-test-workbench_20261117184149

### BR-C10 文本粘贴单次上限
- **对应图谱**：未覆盖
- **规则**：会话内文本粘贴的单次正文上限为 200,000 字符（约 200KB）；超出时拒绝提交并提示当前字数与上限，不静默截断后保存
- **约束对象**：ENT-C5
- **来源 spec**：ai-test-workbench_20261117184149

### BR-C11 单用户登录与登录前置校验
- **对应图谱**：未覆盖
- **规则**：除登录页与登录接口外，所有页面与受保护接口都必须携带有效登录会话（未过期、未吊销）；未认证请求一律跳转登录页或返回 401，且不得返回任何业务数据；只做单账号，不提供注册、口令找回与角色权限
- **约束对象**：ENT-C8、ENT-C9
- **来源 spec**：ai-test-workbench_20261117184149
- 取代：BR-C5

### BR-C12 登录失败限制
- **对应图谱**：未覆盖
- **规则**：口令错误返回不区分原因的统一提示；同一来源连续登录失败达到 5 次后，5 分钟内拒绝该来源的新登录尝试；锁定不影响已建立的登录会话
- **约束对象**：ENT-C8
- **来源 spec**：ai-test-workbench_20261117184149

### BR-C13 凭据与登录令牌安全
- **对应图谱**：未覆盖
- **规则**：口令只保存加盐慢哈希并以恒定时间比较；登录会话令牌只在服务端保存哈希，经 HttpOnly、SameSite=Lax 的 Cookie 传递，HTTPS 下加 Secure；口令、口令哈希与令牌原文不得出现在日志、接口响应、AiCallRecord 与界面中
- **约束对象**：ENT-C8、ENT-C9
- **来源 spec**：ai-test-workbench_20261117184149

### BR-C14 登录凭据来源与失败计数复位
- **对应图谱**：未覆盖
- **规则**：管理员口令由环境变量 `VIGIL_ADMIN_PASSWORD` 提供，服务启动时转存为加盐慢哈希，变量缺失则拒绝启动；口令轮换通过修改环境变量后重启完成；同一来源 IP 的连续登录失败计数在成功登录后清零
- **约束对象**：ENT-C8、ENT-C9
- **来源 spec**：ai-test-workbench_20261117184149

### BR-C15 知识库导入边界与回滚
- **对应图谱**：未覆盖
- **规则**：知识库导入仅接受 `.json .md .markdown`，必须包含合法 `index.json`，并按 AMB-014 约定的单文件大小、文件数量与总量上限校验；类型、大小或结构不合规即拒绝；导入失败或中途出错必须回滚，不留下文件、知识库记录或条目索引
- **约束对象**：ENT-C10、ENT-C11
- **来源 spec**：ai-test-workbench_20261117184149
> 已迁出至 specs/knowledge-base_20261117205011（2026-11-17）

### BR-C16 项目与知识库的关联
- **对应图谱**：未覆盖
- **规则**：ProjectContext 关联 0..n 个知识库；同一项目下知识库名唯一；同名重新导入按 AMB-017 约定创建新版本并保留旧版本只读；删除知识库时同步移除关联
- **约束对象**：ENT-C1、ENT-C10
- **来源 spec**：ai-test-workbench_20261117184149
> 已迁出至 specs/knowledge-base_20261117205011（2026-11-17）

### BR-C17 按编号注入与字符上限
- **对应图谱**：未覆盖
- **规则**：注入内容按「编号 + 标题 + 正文（缺失用摘要）」生成；注入正文与用户提示正文合计不得超过 200,000 字符，超出拒绝调用并显示分段字符数与上限，禁止静默截断；注入的知识库与编号列表必须记入 AiCallRecord 与 SessionEvent
- **约束对象**：ENT-C11、ENT-C7、ENT-C5
- **来源 spec**：ai-test-workbench_20261117184149
> 已迁出至 specs/knowledge-base_20261117205011（2026-11-17）

### BR-C18 知识库内容不落日志
- **对应图谱**：未覆盖
- **规则**：知识库正文与注入内容不得写入应用日志、错误响应与 AiCallRecord 提示摘要；日志只允许记录 kbId、条目编号、字符数与错误类型；知识库中的密钥、令牌或连接串按既有凭据规则处理
- **约束对象**：ENT-C10、ENT-C11
- **来源 spec**：ai-test-workbench_20261117184149
> 已迁出至 specs/knowledge-base_20261117205011（2026-11-17）

### BR-C19 新鲜度与版本冲突只提示不阻断
- **对应图谱**：未覆盖
- **规则**：展示 `index.json` 自带的生成时间与条目新鲜度，缺失标「未知」；同项目下同编号内容摘要不同标「版本冲突」；新鲜度超过 30 天标「可能过期」；提示不单独阻止调用（条目已删除或失效除外），系统不克隆仓库、不解析代码校验新鲜度
- **约束对象**：ENT-C11
- **来源 spec**：ai-test-workbench_20261117184149
> 已迁出至 specs/knowledge-base_20261117205011（2026-11-17）

### BR-C20 删除知识库不影响历史
- **对应图谱**：未覆盖
- **规则**：删除知识库级联删除其条目索引与已存文件，但不修改历史会话、制品与 AiCallRecord；历史记录中的相关编号保留并标注「知识库已删除」；知识库默认永久保留，不做自动过期
- **约束对象**：ENT-C10、ENT-C4、ENT-C7
- **来源 spec**：ai-test-workbench_20261117184149
> 已迁出至 specs/knowledge-base_20261117205011（2026-11-17）

### BR-C21 仓库绑定与令牌只读最小权限
- **对应图谱**：未覆盖
- **规则**：项目可绑定 0..n 个云效 / GitHub 仓库，同一项目下同一提供商 + 同一仓库唯一；访问令牌沿用 AMB-005 服务端加密存储、掩码回显，令牌原文与鉴权请求头不得出现在日志、错误响应、同步记录与 AiCallRecord；界面提示使用只读最小权限令牌，系统不发起任何仓库写操作；绑定数量不设硬上限（0..n），界面提示建议 ≤ 5 个（AMB-025）；云效默认域名 `https://openapi-rdc.aliyuncs.com` + `/oapi/v1/codeup`，允许填地域域名（AMB-024）
- **约束对象**：ENT-C12、ENT-C1
- **来源 spec**：ai-test-workbench_20261117184149
> 已迁出至 specs/repo-integration_20261117205011（2026-11-17）

### BR-C22 连通性测试四类结果
- **对应图谱**：未覆盖
- **规则**：连通性测试只发起一次只读请求并在 10s 内返回，结果分为成功 / 鉴权失败 / 网络失败 / 权限不足四类；权限不足不得归为网络失败，网络失败不得归为令牌无效；测试不写会话、制品或 AiCallRecord
- **约束对象**：ENT-C12
- **来源 spec**：ai-test-workbench_20261117184149
> 已迁出至 specs/repo-integration_20261117205011（2026-11-17）

- **规则**：同步只由用户点击触发，同一绑定禁止并发；一次同步保存仓库、全部分支与最近 100 条提交（AMB-023 已确认）的元数据快照，仓库 / 分支快照全量覆盖、提交滚动保留 100 条，不保存代码文件、不建立代码索引、不做定时任务与 Webhook；失败时保留上次成功元数据与上次同步时间，并记录错误分类
- **约束对象**：ENT-C12、ENT-C13、ENT-C14
- **来源 spec**：ai-test-workbench_20261117184149
> 已迁出至 specs/repo-integration_20261117205011（2026-11-17）

- **规则**：文件内容只经供应商 API 按指定 ref 读取单个文件；超过单次读取上限 1 MiB（AMB-020 已确认）拒绝并显示大小与上限；二进制或非 UTF-8 内容拒绝预览；路径含 `..`、绝对路径或 ref 非法时在发起请求前拒绝；内容不落盘、不写会话制品与 AiCallRecord，引用进分析时计入 200,000 字符上限
- **约束对象**：ENT-C12、ENT-C15
- **来源 spec**：ai-test-workbench_20261117184149
