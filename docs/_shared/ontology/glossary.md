# Glossary

### TERM-C1 入口
- **对应图谱**：未覆盖
- **定义**：工作台首页提供给用户的一类任务起点，共 6 个：生成测试用例、分析 bug、排查日志、分析 SQL、生成回归清单、生成测试报告；入口只负责导航与任务发起，业务能力属各自域。
- **避免的叫法**：菜单、按钮、功能模块
- **来源 spec**：ai-test-workbench_20261117184149

### TERM-C13 用例库（入口）
- **对应图谱**：未覆盖
- **定义**：六个入口之一，原名「生成测试用例」；生成用例是该入口内部的能力，不作为独立入口名。入口清单为：用例库、分析 bug、排查日志、分析 SQL、生成回归清单、生成测试报告。
- **避免的叫法**：生成测试用例（作为入口名）、用例生成入口
- **来源 spec**：ai-test-workbench_20261117184149
- 取代：TERM-C1

### TERM-C2 分析会话（Session）
- **对应图谱**：未覆盖
- **定义**：用户为完成一次分析任务而创建的工作单元，绑定一个项目、一个入口与一个模型，按时间追加输入、调用与制品事件，状态为进行中 / 已完成 / 失败。
- **避免的叫法**：对话、聊天、任务
- **来源 spec**：ai-test-workbench_20261117184149

### TERM-C3 制品（Artifact）
- **对应图谱**：未覆盖
- **定义**：会话产生的文件级输入或输出，按 `sessions/<sessionId>/` 隔离存放，其他域只按 artifactId 引用。
- **避免的叫法**：附件、文件、输出
- **来源 spec**：ai-test-workbench_20261117184149

### TERM-C4 AI 调用记录（AiCallRecord）
- **对应图谱**：未覆盖
- **定义**：一次经基座发起的模型调用的审计记录，含模型、状态、耗时、重试次数与提示摘要，每次调用必有一条（成功或失败）。
- **避免的叫法**：日志、埋点、调用日志
- **来源 spec**：ai-test-workbench_20261117184149

### TERM-C5 项目上下文（ProjectContext）
- **对应图谱**：未覆盖
- **定义**：一个被测项目的背景信息集合（项目名、仓库地址、技术栈、需求来源、备注），供该项目的所有会话共用。
- **避免的叫法**：工作空间、项目配置
- **来源 spec**：ai-test-workbench_20261117184149

### TERM-C6 提供商（Provider）
- **对应图谱**：未覆盖
- **定义**：一个外部 AI 模型服务端点，由名称、协议、baseURL、加密后的密钥与启用状态描述。
- **避免的叫法**：厂商、渠道、模型
- **来源 spec**：ai-test-workbench_20261117184149

### TERM-C7 模型绑定（ModelBinding）
- **对应图谱**：未覆盖
- **定义**：登记在某个提供商下的具体模型及其默认参数（temperature、max_tokens），是会话调用时可选的目标。
- **避免的叫法**：模型配置、模型实例
- **来源 spec**：ai-test-workbench_20261117184149

### TERM-C8 占位降级
- **对应图谱**：未覆盖
- **定义**：入口对应的业务域尚未交付时，入口仍常驻可见，进入后展示所属域与当前状态说明，不创建会话、不发起模型调用。
- **避免的叫法**：禁用、空页面、待开发
- **来源 spec**：ai-test-workbench_20261117184149

### TERM-C9 登录会话（LoginSession）
- **对应图谱**：未覆盖
- **定义**：用户用管理员口令登录成功后，服务端签发并保存哈希的访问凭据容器，可过期、可吊销；只用于访问控制，与分析会话（Session）不是同一对象。
- **避免的叫法**：会话（单独使用时易与分析会话混淆）、token 配置
- **来源 spec**：ai-test-workbench_20261117184149

### TERM-C10 知识库（KnowledgeBase）
- **对应图谱**：未覆盖
- **定义**：由外部本体工具（`ontology-builder-native` + `ontology-consumption`）产出的、按编号组织的业务知识文件集合（`index.json` + `.md`），由用户上传到某个项目，供浏览与按编号注入；工作台只读，不在线编辑。
- **避免的叫法**：知识图谱、向量库、文档库
- **来源 spec**：ai-test-workbench_20261117184149
> 已迁出至 specs/knowledge-base_20261117205011（2026-11-17）

### TERM-C11 知识库条目（KnowledgeEntry）
- **对应图谱**：未覆盖
- **定义**：知识库中按编号（如 `ENT-123`、`BR-045`）标识的一条业务知识，含类型、标题、字段、表、代码路径、一跳邻居与新鲜度；编号是浏览、检索与注入的稳定引用键。
- **避免的叫法**：节点、记录、文档片段
- **来源 spec**：ai-test-workbench_20261117184149
> 已迁出至 specs/knowledge-base_20261117205011（2026-11-17）

### TERM-C12 知识注入（Knowledge Injection）
- **对应图谱**：未覆盖
- **定义**：会话发起调用时，把用户勾选的若干知识库条目按「编号 + 标题 + 正文（缺失用摘要）」拼入提示上下文；注入正文与用户提示正文合计受 200,000 字符上限约束，注入的知识库与编号记入 AiCallRecord 与 SessionEvent。
- **避免的叫法**：RAG、检索增强、前置知识
- **来源 spec**：ai-test-workbench_20261117184149
> 已迁出至 specs/knowledge-base_20261117205011（2026-11-17）

### TERM-C14 仓库绑定（Repository Binding）
- **对应图谱**：未覆盖
- **定义**：项目与一个外部代码仓库（云效 Codeup 或 GitHub）之间的只读关联，包含提供商、仓库标识、加密访问令牌与最近同步状态；一个项目可有 0..n 个绑定。
- **避免的叫法**：仓库连接、代码接入、克隆任务
- **来源 spec**：ai-test-workbench_20261117184149
> 已迁出至 specs/repo-integration_20261117205011（2026-11-17）

### TERM-C15 仓库元数据同步（Repository Metadata Sync）
- **对应图谱**：未覆盖
- **定义**：用户手动触发的一次只读拉取，获取仓库、分支、最近提交与目录树元数据并保存为快照；不是克隆，不下载代码文件，不建立代码索引。
- **避免的叫法**：仓库克隆、代码同步、拉取代码
- **来源 spec**：ai-test-workbench_20261117184149
> 已迁出至 specs/repo-integration_20261117205011（2026-11-17）

### TERM-C16 按需文件读取（On-demand File Read）
- **对应图谱**：未覆盖
- **定义**：用户选定目录树中的单个文件与 ref 后，经供应商 API 读取一次文件内容用于查看或分析引用；受单文件大小上限与 UTF-8 文本限制，内容不落盘。
- **避免的叫法**：文件下载、缓存文件、代码索引
- **来源 spec**：ai-test-workbench_20261117184149
> 已迁出至 specs/repo-integration_20261117205011（2026-11-17）
