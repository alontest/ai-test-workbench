# Interaction Design — Flowchart

每个流程图对应一个 US，均含开始 / 结束节点与带标签的决策分支。图中「基线」指同步产生的元数据快照；「实时」指直接请求供应商接口。

## US-017：绑定云效 / GitHub 仓库并保存访问令牌

```mermaid
flowchart TD
  A([打开项目上下文页]) --> B[在项目详情表单下方的「仓库绑定」区块点击「+ 添加绑定」]
  B --> C[选择提供商：云效 Codeup / GitHub]
  C --> D[填写仓库标识与访问令牌<br/>可选填写 API 域名]
  D --> E{必填完整、格式合法且为 https:// ?}
  E -- 否 --> E1[逐字段提示原因<br/>不写入绑定或令牌] --> D
  E -- 是 --> F{同项目同提供商 + 同仓库已绑定?}
  F -- 是 --> F1[拒绝并提示重复<br/>原绑定与令牌保持不变] --> D
  F -- 否 --> G[服务端加密存储令牌<br/>创建绑定并返回 bindingId]
  G --> H[列表与详情只显示掩码<br/>提示只读最小权限、不克隆、不建索引]
  H --> I([绑定创建完成])
```

## US-018：测试仓库连通性

```mermaid
flowchart TD
  A([点击「测试连接」]) --> B{绑定已保存还是表单当前值?}
  B -- 表单当前值 --> B1[使用临时凭证，不落库、不写日志]
  B -- 已保存绑定 --> B2[使用该绑定令牌]
  B1 --> C[发起一次只读请求，10s 超时]
  B2 --> C
  C --> D{结果分类}
  D -- 成功 --> S[展示默认分支 / 最近提交时间<br/>保存后状态为「已连接」]
  D -- 401 / 403 鉴权语义 --> X[鉴权失败：提示重新填写<br/>已保存绑定标「令牌失效」]
  D -- 不可达 / DNS / 拒绝 / 超时 --> N[网络失败：给可读原因与重试建议<br/>不写同步记录、不改已同步元数据]
  D -- 令牌有效但无权访问 --> P[权限不足：提示所需只读权限范围]
  X --> R[记录测试时间与分类]
  N --> R
  P --> R
  S --> R
  R --> T{保存前测试且表单字段已修改?}
  T -- 是 --> T1[结果条转「已失效，请重新测试」] --> A
  T -- 否 --> E([结束：不写会话、制品与 AiCallRecord])
```

## US-019：手动同步仓库元数据

```mermaid
flowchart TD
  A([点击「同步」]) --> B{该绑定正在同步?}
  B -- 是 --> B1[返回「同步进行中」并阻止并发<br/>不产生第二次记录] --> Z([结束])
  B -- 否 --> C[拉取仓库信息、全部分支与最近 100 条提交]
  C --> D{结果}
  D -- 成功 --> S[写入元数据基线<br/>更新上次同步时间、耗时与结果]
  D -- 鉴权失败 --> X[记录失败与原因<br/>保留上次成功元数据与时间]
  D -- 网络失败 --> N[记录失败与原因<br/>保留上次成功元数据与时间]
  D -- 429 或等价限流 --> L[展示「供应商限流」<br/>可重试时间（若提供）；不自动重试]
  S --> E([展示上次同步时间、耗时与结果])
  X --> E
  N --> E
  L --> E
```

## US-020：选择仓库与分支

```mermaid
flowchart TD
  A([打开仓库浏览页]) --> B{元数据已同步?}
  B -- 否 --> B1[空态：先同步<br/>提供「去同步」入口，不返回错误页] --> Z([结束])
  B -- 是 --> C{令牌是否失效?}
  C -- 是 --> C1[提示「令牌失效」并提供重填入口<br/>展示上次同步基线与时间标记]
  C -- 否 --> D[实时请求仓库列表]
  C1 --> D
  D --> E[按名称 / 关键词检索并选择仓库<br/>默认选中绑定仓库]
  E --> F[实时请求分支列表（供应商分页 + 名称检索）]
  F --> G[默认选中默认分支]
  G --> H{用户切换分支?}
  H -- 是 --> H1[提交列表与目录树随之切换] --> H2([浏览新的分支])
  H -- 否 --> H2
```

## US-021：浏览提交与目录树

```mermaid
flowchart TD
  A([选定仓库与分支]) --> B[实时加载提交列表]
  B --> C{有提交?}
  C -- 否 --> C1[空态：当前分支没有提交] --> E([结束])
  C -- 是 --> D[按时间倒序展示 sha 短号 / 标题 / 作者 / 时间<br/>支持翻页]
  D --> F[逐级实时展开目录树]
  F --> G{单个目录条目是否被供应商分页限制?}
  G -- 是 --> G1[显示「还有更多（n 条未加载）」<br/>按页加载] --> F
  G -- 否 --> H{供应商标记 truncated?}
  H -- 是 --> H1[提示「目录树不完整，请逐级浏览」<br/>不当作完整结果] --> I
  H -- 否 --> I[展示名称、类型、文件大小]
  I --> J{查看提交或节点详情?}
  J -- 是 --> J1[展示仓库、分支 / ref、路径与文件大小<br/>不写入 AiCallRecord 正文] --> E
  J -- 否 --> E
```

## US-022：按需读取单个文件内容

```mermaid
flowchart TD
  A([在目录树或提交中选定文件与 ref]) --> B[点击查看]
  B --> C{路径含 ..、绝对路径或非法 ref?}
  C -- 是 --> C1[请求前拒绝并说明原因<br/>不产生读取记录] --> Z([结束])
  C -- 否 --> D[请求供应商单文件接口]
  D --> E{文件大小是否超过 1 MiB?}
  E -- 是 --> E1[拒绝并显示实际大小与上限 1,048,576 字节<br/>不截断后冒充完整内容] --> Z
  E -- 否 --> F{二进制或非合法 UTF-8?}
  F -- 是 --> F1[拒绝预览并说明不支持<br/>不展示乱码] --> Z
  F -- 否 --> G[展示路径、ref、大小、读取时间与内容]
  G --> H[不写会话制品与 AiCallRecord<br/>引用进分析计入 200,000 字符]
  H --> Z
```

## US-023：处理令牌失效与撤销仓库绑定

```mermaid
flowchart TD
  A([同步 / 浏览 / 读文件返回 401 或 403]) --> B[绑定标「令牌失效」]
  B --> C[项目上下文页与相关入口统一提示重填<br/>不重复弹错；仍可查看上次同步基线]
  C --> D{用户选择}
  D -- 重新填写令牌 --> E[输入新令牌并测试连接]
  E --> F{测试成功?}
  F -- 否 --> C
  F -- 是 --> G[保存后恢复「已连接」<br/>bindingId、元数据与历史记录不变] --> Z([结束])
  D -- 撤销绑定 --> H[二次确认并列出后果]
  H --> I{确认?}
  I -- 否 --> C
  I -- 是 --> J[状态「已解绑」、删除加密令牌<br/>此后不再发起任何请求]
  J --> K[仓库 / 分支 / 提交快照保留，标「已解绑」只读可查<br/>目录树与读文件入口置灰]
  K --> L[历史会话、制品与调用记录不变]
  L --> M{重新绑定同一仓库?}
  M -- 是 --> M1[生成新的 bindingId 与新令牌<br/>不复用旧令牌与旧同步记录] --> Z
  M -- 否 --> Z
```
