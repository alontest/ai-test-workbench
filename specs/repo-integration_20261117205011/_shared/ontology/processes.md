# Processes

### BP-C9 仓库绑定与连通性测试
- **对应图谱**：未覆盖
- **触发条件**：用户在项目上下文页填写提供商、令牌与仓库标识并保存，或点击「测试连接」
- **操作的对象**：ENT-C12（创建或更新绑定、加密令牌、记录测试结果与状态）；测试只发一次只读请求，10s 内返回四类结果之一
- **来源 spec**：repo-integration_20261117205011

### BP-C10 仓库元数据手动同步
- **对应图谱**：未覆盖
- **触发条件**：用户点击「同步」
- **操作的对象**：ENT-C12（更新上次同步时间与状态）、ENT-C13（写入同步记录）、ENT-C14（写入仓库 / 分支 / 提交 / 目录树元数据快照）；失败保留旧快照，不克隆、不建索引
- **来源 spec**：repo-integration_20261117205011

### BP-C11 按需读取仓库文件
- **对应图谱**：未覆盖
- **触发条件**：用户在目录树或提交中选定单个文件与 ref 并请求查看
- **操作的对象**：ENT-C12（读取绑定令牌）、ENT-C15（记录读取目标与结果）；内容经供应商 API 读取，不落盘、不写会话制品与 AiCallRecord
- **来源 spec**：repo-integration_20261117205011
