# Glossary

### TERM-C14 仓库绑定（Repository Binding）
- **对应图谱**：未覆盖
- **定义**：项目与一个外部代码仓库（云效 Codeup 或 GitHub）之间的只读关联，包含提供商、仓库标识、加密访问令牌与最近同步状态；一个项目可有 0..n 个绑定。
- **避免的叫法**：仓库连接、代码接入、克隆任务
- **来源 spec**：repo-integration_20261117205011

### TERM-C15 仓库元数据同步（Repository Metadata Sync）
- **对应图谱**：未覆盖
- **定义**：用户手动触发的一次只读拉取，获取仓库、分支、最近提交与目录树元数据并保存为快照；不是克隆，不下载代码文件，不建立代码索引。
- **避免的叫法**：仓库克隆、代码同步、拉取代码
- **来源 spec**：repo-integration_20261117205011

### TERM-C16 按需文件读取（On-demand File Read）
- **对应图谱**：未覆盖
- **定义**：用户选定目录树中的单个文件与 ref 后，经供应商 API 读取一次文件内容用于查看或分析引用；受单文件大小上限与 UTF-8 文本限制，内容不落盘。
- **避免的叫法**：文件下载、缓存文件、代码索引
- **来源 spec**：repo-integration_20261117205011
