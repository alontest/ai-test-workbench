# Interaction Design — Design

## 设计决策

### 决策 1：复用 workbench-core 的外壳、设计 token 与登录态
- **选择**：知识库全部页面挂在 core 的 AppShell 内：固定侧边栏 `248px` + 顶栏 `64px` + 内容区（最大 `1280px`）；入口放在侧边栏「基座管理」分组（项目上下文 / AI 提供商与模型 / 调用记录 / **知识库**）；全部路由受 `AuthGate` 保护。配色沿用 core 的 Dark-first 近黑中性 + 绿色强调。
- **理由**：知识库是项目级只读资产，与基座管理同级；用户已定「复用 core 的 AppShell、设计 token、登录态」，另建外壳会造成两套导航与两套主题。
- **备选方案**：放进「项目上下文」页签；做成第七个业务入口；独立弹窗式注入。
- **权衡**：列表在「基座管理」内多一层导航；页面信息密度受既有外壳约束。

### 决策 2：导入、浏览、注入是三条独立路径，注入内嵌在会话面板
- **选择**：`/knowledge-bases`（列表）→ `/knowledge-bases/import`（导入）→ `/knowledge-bases/:kbId`（浏览）→ 条目详情；注入选择器内嵌在会话详情的「发起调用」面板，不弹窗。
- **理由**：导入面向文件校验，浏览面向按编号查业务概念；注入必须与提示正文同屏才能看到 200,000 字符合计（AC-014-1）。
- **权衡**：会话面板变长；小屏需上下堆叠。

### 决策 3：只读资产 + 版本链，旧版本只读
- **选择**：同名重新导入生成新版本；列表每个知识库只展示最新版本一行 +「另有 N 个旧版本（只读）」；浏览页默认最新版本，可在版本下拉切到旧版本并显示「已被新版本取代」。
- **理由**：知识库由外部工具生成，工作台不编辑；版本链让「历史调用当时依据什么」可回查。
- **权衡**：列表不展开旧版本，用户需进入浏览页切换。

### 决策 4：失效条目「剔除 + 阻塞式确认」
- **选择**：发起调用前校验所选条目；存在已删除 / 已被取代 / 不存在条目时，先剔除并用模态对话框列出被剔除编号。确认 → 用剩余有效条目照常发起并产生 AiCallRecord；取消 → 不发起、不产生记录，弹窗关闭，失效条目在列表中自动取消勾选并标「不可用」。
- **理由**：AC-014-4（2026-11-18 按 AMB-026 修正）明确「不静默降级」；内联提示容易被忽略，阻塞确认保证用户知道本次实际注入了什么。
- **权衡**：每次存在失效条目多一次确认；换来确定性。
- **状态约定**：确认按钮文案「继续调用（使用 N 条有效条目）」；取消按钮「取消」；对话框不可点击遮罩关闭，Esc 等同取消。

### 决策 5：风险提示只用 warning / 中性徽标，不用 destructive
- **选择**：「版本冲突」「可能过期」用 `--color-warning`；「新鲜度未知」「正文缺失」「知识库已删除」用 `muted-foreground` + `border` 中性徽标；只有导入校验失败、删除、超限、失效条目用 `--color-destructive`。
- **理由**：AMB-016 明确「只提示不阻止」；红色会让用户误以为条目不可用。

### 决策 6：字符预算分段展示，超限拒绝不截断
- **选择**：选择器实时显示「已选 N 条 · 注入 X 字符 · 提示 Y 字符 · 合计 Z / 200,000」；Z > 90% 用 warning，Z > 200,000 用 destructive 并显示超出量、禁用「发起调用」；任何情况下都不截断条目或提示。
- **理由**：AC-014-1 / AC-014-3；200,000 常量由 core 单点定义（`AW_PROMPT_MAX_CHARS`），本 spec 只显示。
- **已确认**：X 按完整注入块统计（编号 + 标题 + 正文或摘要 + 知识库名与生成时间），与 core 对最终 prompt 的 200,000 校验同口径（UXAMB-001；answers.md：「其他按建议」）。

### 决策 7：删除只从列表行发起，无撤销
- **选择**：删除按钮只在知识库列表行出现；确认对话框列明「知识库及其全部版本、条目索引、已存文件、项目关联」与「历史会话 / 调用记录不变」；执行中「删除中…」禁用按钮，失败保留对话框可重试。
- **理由**：删除影响整个版本链，从列表发起能先看到项目与版本上下文；需求明确无撤销、无自动过期。

## 设计系统

沿用 workbench-core 的既有设计系统（`specs/ai-test-workbench_20261117184149/interaction-design/design.md` 与 `docs/design-system.md`），不重新检索、不新增 token。

- **风格**：Dark-first 的工程师工作台；暗色近黑中性（背景 `#0A0A0B`、卡片 `#141416`、弱化表面 `#1C1C1F`、边框 `#2A2A2E`），绿色 `#22C55E` 只承担运行 / 成功 / 焦点；等宽字体承担编号、代码路径与正文预览。
- **为何不执行 ui-ux-pro-max**：本阶段判定为「已有设计系统」的模块新增（core 已完成设计系统并经用户确认，用户明确要求复用），按阶段契约跳过全新模块的检索步骤；只执行线框图、token 登记与流程图。
- **字体**：正文 IBM Plex Sans + 中文回退；标题 / 编号 / 代码 JetBrains Mono。
- **效果**：极轻抬升（`--shadow-sm/md/lg`），150–240ms 过渡，无弹跳动画；尊重 `prefers-reduced-motion`。
- **反模式**：不使用浅色默认、重阴影、emoji 图标、hover-only 交互、移除焦点环；不把知识库正文当 HTML 渲染。

## 信息架构与路由

| 路由 | 页面 | US |
|------|------|----|
| `/knowledge-bases` | 知识库列表（项目筛选、版本、删除、导入入口） | US-012 / US-015 / US-016 |
| `/knowledge-bases/import` | 导入知识库（项目选择、多文件、逐项校验、导入报告） | US-012 |
| `/knowledge-bases/:kbId` | 知识库浏览（筛选、检索、类型分栏、条目列表） | US-013 / US-015 |
| `/knowledge-bases/:kbId/entries/:code` | 条目详情（摘要、正文、字段、表、代码路径、一跳邻居、冲突） | US-013 / US-015 |
| `/sessions/:id`（core 页面） | 会话调用面板内嵌「知识库注入」选择器与阻塞确认 | US-014 / US-015 |
| `/projects`（core 页面） | 项目上下文页内挂载「关联知识库」区块 | US-012 AC-012-6 |

全部路由受 `AuthGate` 保护：未认证跳 `/login?next=<原路径>`，接口 401；`next` 只接受站内路径。

## 线框图

### 知识库列表页（US-012 / US-015 / US-016）

**Purpose**: 在一个地方看到当前项目（或全部项目）的知识库、最新版本、生成时间与条目数，发起导入或删除。

**Layout**:
```
+----------------------+-------------------------------------------------------+
| (AppShell sidebar)   | 知识库                              [+ 导入知识库]    |
|  工作台               +-------------------------------------------------------+
|   首页               | 项目 [全部 ▼]                          共 2 个知识库     |
|   分析会话           | +---------------------------------------------------+ |
|  入口                 | | 名称               项目    版本  生成时间    条目  状态    操作        | |
|  基座管理             | | 支付台业务知识库   支付台  v3    11-17 09:12  42   已就绪  [浏览][删除] | |
|   项目上下文          | |   另有 1 个旧版本（只读）                                              | |
|   AI 提供商与模型     | | 风控规则知识库     风控台  v1    未知         18   已就绪  [浏览][删除] | |
|   调用记录            | +---------------------------------------------------+ |
|   知识库 ←            | 只读导入：工作台不修改上传文件，也不在线编辑条目；同名重新导入     |
|                      | 会生成新版本，旧版本只读保留。                                  |
+----------------------+-------------------------------------------------------+
```

**Key Elements**:
| Element | Type | Behavior |
|---------|------|----------|
| 项目筛选 | Select | 全部项目 / 单个项目；变更即过滤；默认全部；保留在 URL query `project` |
| 导入知识库 | Primary button | 跳 `/knowledge-bases/import`；未选具体项目时导入页要求先选 |
| 知识库行 | Table row | 名称、项目、最新版本、生成时间（缺失「未知」）、条目数、状态「已就绪」、操作 |
| 旧版本提示 | Inline text | 存在旧版本时显示「另有 N 个旧版本（只读）」，不展开行 |
| 浏览 | Row button | 进入 `/knowledge-bases/:kbId`，默认最新版 |
| 删除 | Row button (danger) | 打开删除确认对话框；无撤销 |
| 只读说明 | Static text | 页脚固定说明 |
| 关联知识库区块（项目上下文） | Embedded section | 选中项目时展示最多 3 条摘要 +「查看全部」；无知识库显示空态 +「导入知识库」 |

**States**:
- default：项目筛选 + 表格 + 只读说明
- loading：标题 + 4 行骨架（超过 400ms 才显示）
- success：导入 / 删除后回列表，顶部 banner「导入成功 · 新增 1 个知识库」或「知识库已删除」
- error：可重试错误块，保留项目筛选
- empty：「还没有知识库」+「导入知识库」+ 说明「先在本地用 ontology-builder-native / ontology-consumption 生成知识库文件」

### 导入知识库页（US-012）

**Purpose**: 选择项目与本地知识库文件，逐项校验后提交，得到导入报告。

**Layout**:
```
+----------------------+-------------------------------------------------------+
| (sidebar)            | ← 知识库                                              |
|                      | 导入知识库 · 项目 [支付台 ▼]                          |
|                      | +---------------------------------------------------+ |
|                      | | 拖拽文件到这里，或点击选择（可多选）                | |
|                      | | 仅 .json / .md / .markdown；必须包含 index.json     | |
|                      | | index.json ≤20MB · 其他单文件 ≤10MB · 单次 ≤50 个   | |
|                      | | 单库合计 ≤100MB                                     | |
|                      | +---------------------------------------------------+ |
|                      | 已选择 3 个文件 · 合计 240 KB                         |
|                      | ✓ index.json            240 KB  通过                 |
|                      | ✓ glossary.md            12 KB  通过                 |
|                      | ✗ notes.txt               3 KB  不支持 .txt          |
|                      | [!] 存在 1 个不合规文件，请移除或替换后再提交。       |
|                      |                                 [取消] [提交导入]     |
|                      |---------------------------------------------------|
|                      | 导入报告（成功态）                                    |
|                      | 已导入 3 条 · 跳过 2 条                               |
|                      |  • 第 128 行：缺少编号，已跳过                        |
|                      |  • 第 302 行：编号重复（TERM-001），已跳过            |
|                      | [查看知识库]                                          |
+----------------------+-------------------------------------------------------+
```

**Key Elements**:
| Element | Type | Behavior |
|---------|------|----------|
| 项目选择 | Select | 必选；无项目时禁用提交并给「新建项目」链接 |
| 文件选择区 | Dropzone + file input | 多选，`accept=".json,.md,.markdown"`；拖拽或点击；键盘可触发 |
| 校验规则说明 | Static text | 白名单、必须含 `index.json`、20MB / 10MB / 50 个 / 100MB |
| 已选摘要 | Inline text | 「已选择 N 个文件 · 合计 X」；0 个时显示「请选择至少包含 index.json 的文件」 |
| 校验结果列表 | List | 每文件一行：文件名、大小、结果；不合规标红并给出具体原因；可移除 |
| 整体错误 | Error block | 缺少 `index.json`、数量或合计超限显示在列表上方 |
| 提交导入 | Primary button | 有错误或无文件时禁用；提交中「校验中…」；服务端结构错误时不创建知识库 |
| 导入报告 | Result card | 成功：知识库名 + 版本 + 已导入条目数 + 跳过条目（行号 + 原因）；同名提示新版本 |
| 取消 | Secondary button | 返回列表，丢弃已选文件 |

**States**:
- default：空选择区 + 规则说明；提交禁用
- loading：「校验中…」+ 列表只读 + 按钮内联 loading
- success：报告 +「查看知识库」
- error：类型不支持 / 缺少 `index.json` / 超出大小 / 超出数量 / 合计超限 / 非法 JSON / 缺版本标识 / 缺条目集合 / 条目集合为空，逐项说明，不写文件、不建库
- empty：未选择文件时的空选择区说明；已选但校验后 0 个可导入条目 → 整体失败说明「没有可导入的条目，导入已回滚，未创建知识库」
- 失败后已选文件保留，允许移除 / 替换后重试；只有「取消」丢弃

### 知识库浏览页（US-013 / US-015）

**Purpose**: 按项目、知识库、版本与类型筛选条目，支持编号 / 关键词检索并进入详情。

**Layout**:
```
+----------------------+-------------------------------------------------------+
| (sidebar)            | 知识库浏览   [支付台业务知识库 v3 ▼]                  |
|                      +-------------------------------------------------------+
|                      | 项目 [支付台 ▼]  知识库 [支付台业务知识库 v3 ▼]        |
|                      | 检索 [TERM- / 支付单________]              共 8 条     |
|                      | [全部 8][术语 3][实体 2][状态 1][规则 1][流程 1][接口 0]… |
|                      | +---------------------------------------------------+ |
|                      | | TERM-001  支付单         术语  [版本冲突] [12 天前] | |
|                      | | ENT-002   支付订单       实体  [可能过期]           | |
|                      | | BR-003    重复支付拦截   规则  [正文缺失]           | |
|                      | | BP-004    支付回调处理   流程  [新鲜度未知]         | |
|                      | +---------------------------------------------------+ |
+----------------------+-------------------------------------------------------+
```

**Key Elements**:
| Element | Type | Behavior |
|---------|------|----------|
| 项目 / 知识库筛选 | Selects | 项目默认「全部」；知识库下拉收敛到所选项目，含最新版与旧版本（旧版标「只读」）；默认最新版 |
| 版本切换 | Select | 选旧版本时顶部显示 info banner「当前查看 v2，已被新版本取代」+「查看最新版」 |
| 检索框 | Search input | 编号前缀（`TERM-`）、完整编号（`TERM-001`）、关键词（标题 / 摘要 / 正文）；输入即筛选，结果高亮编号 |
| 类型分栏 | Tab group | 全部 / 术语 / 实体 / 状态 / 业务规则 / 流程 / 接口 / 领域事件 / 其他；计数随筛选变化；空分组 disabled |
| 条目行 | Table row | 编号（mono）+ 标题 + 类型 + 所属知识库与版本 + 状态徽标；点击进详情 |
| 空态 | Empty state | 「没有符合条件的条目」+「清除筛选」；不显示错误 |

**States**:
- default：筛选 + 类型分栏 + 列表
- loading：骨架行
- success：列表；检索命中时显示「共 N 条」
- error：可重试错误块，保留筛选与检索词
- empty：空态 + 清除筛选
- superseded：旧版本 banner + 每条带「已被新版本取代」

### 条目详情页（US-013 / US-015）

**Purpose**: 在注入前核对一条业务概念的完整定义、代码落点、来源与新鲜度。

**Layout**:
```
+----------------------+-------------------------------------------------------+
| (sidebar)            | ← 知识库浏览                                          |
|                      | TERM-001 支付单          [术语] [可能过期] [版本冲突] |
|                      | 所属：支付台业务知识库 v3 · 生成时间 2026-11-17 09:12   |
|                      | 来源：index.json + glossary.md                        |
|                      | +---------------------+ +---------------------------+ |
|                      | | 摘要                | | [!] 版本冲突               | |
|                      | | 一次支付行为的业务  | | 同编号摘要不同，来源：      | |
|                      | | 单据…               | |  • 支付台业务知识库 v2      | |
|                      | +---------------------+ |    生成于 2026-10-02 14:30  | |
|                      | | 正文（来源 glossary.md）| 只提示，不阻止注入。       | |
|                      | | 支付单是支付台对一次…  | +---------------------------+ |
|                      | +---------------------+ | [!] 可能过期                 | |
|                      | 字段：支付单号 / 金额 / 状态 | 新鲜度 2026-10-01（48 天前） | |
|                      | 表：pay_order …        | +---------------------------+ |
|                      | 代码路径：src/pay/…    |                               | |
|                      | 一跳邻居：ENT-002 → ST-005 →                          | |
+----------------------+-------------------------------------------------------+
```

**Key Elements**:
| Element | Type | Behavior |
|---------|------|----------|
| 标题与徽标 | Heading + pills | 编号 + 标题 + 类型；新鲜度（「N 天前」/「可能过期」/「未知」）；版本冲突；「已被新版本取代」 |
| 来源信息 | Static text | 所属知识库 + 版本 + 生成时间（缺失「未知」）+ 来源文件 |
| 摘要 | Text block | 来自 `index.json`，始终展示 |
| 正文 | Text block | 有 `.md` 正文时展示；缺失时展示摘要并标「正文缺失」，不冒充正文 |
| 字段 / 表 / 代码路径 | Definition list | 逐项列出；缺失显示「—」，不推测 |
| 一跳邻居 | Link list | 邻居编号可点击；目标不存在时提示「该项目下没有编号 X」 |
| 版本冲突 | Warning card | 冲突来源：知识库名 + 版本 + 生成时间；说明「只提示，不阻止注入」 |
| 最新版跳转 | Text link | 被取代时提供「查看最新版本」 |
| 返回 | Text link | 回浏览页，保留筛选与检索词 |

**States**:
- default：完整详情
- loading：骨架
- success：完整详情
- error：条目不存在或已随知识库删除 → 说明 + 返回浏览；知识库已删除时标「知识库已删除」
- empty：所有明细字段缺失 → 只展示编号、标题、摘要与「字段信息缺失」，不渲染空表格
- body-missing：正文缺失，展示摘要 + 中性徽标
- superseded：版本被取代提示 + 最新版跳转

### 会话调用面板 · 知识库注入（US-014 / US-015）

**Purpose**: 在会话内按编号勾选条目，实时核对字符预算，确认后把知识注入本次调用。

**Layout**:
```
+----------------------------------------------+
| 发起调用                                     |
| 提示（必填）                                 |
| [请分析以下登录报错的可能原因_____________]   |
| 知识库注入（按编号勾选）                     |
|  支付台业务知识库 v3 · 生成于 11-17 09:12     |
|  [✓] TERM-001 支付单        术语 [可能过期]  |
|  [✓] ENT-002  支付订单      实体 [可能过期]  |
|  [ ] BR-003   重复支付拦截  规则 [正文缺失]  |
|  [ ] API-006  创建支付接口  接口 [版本冲突]  |
| 已选 2 条 · 注入 1,204 字符 · 提示 19 字符   |
| 合计 1,223 / 200,000 字符                    |
| [!] 超出上限：提示 200,001 + 注入 1,204      |
|     = 201,205 / 200,000，超出 1,205 字符。   |
|     不会截断，请取消勾选或缩短提示。          |
|                         [ 发起调用 ]         |
+----------------------------------------------+
```

**Key Elements**:
| Element | Type | Behavior |
|---------|------|----------|
| 条目选择器 | Checkbox list | 只列当前会话项目的最新版本条目；每行：编号 + 标题 + 类型 + 新鲜度 / 冲突 / 正文缺失徽标；顶部显示知识库名与生成时间 |
| 已选摘要 | Inline text | 「已选 N 条 · 注入 X 字符 · 提示 Y 字符 · 合计 Z / 200,000」；勾选、取消与输入提示时实时更新 |
| 预算条 | Progress bar | 合计占比；>90% warning、>100% destructive；始终显示不截断说明 |
| 超限错误 | Error block | 显示提示 / 注入 / 合计 / 上限 / 超出量，明确「不会截断」；「发起调用」禁用 |
| 失效条目 | 阻塞确认对话框 | 发起前剔除并列编号；确认继续 / 取消不发起（见下） |
| 发起调用 | Primary button | 提示非空且合计未超限时可用；调用中「调用中… 最长 120s」，选择器与提示只读 |
| 注入结果 | Timeline event | 知识库名 + 版本 + 编号列表 + 字符数；不记录正文；已删除知识库编号旁标「知识库已删除」 |
| 选择保留 | Session state | 切换页面不丢失；刷新或重新进入会话重置；不持久化到服务端 |

**States**:
- default：提示 + 选择器 + 预算条
- loading：调用中，选择器与提示只读
- success：时间线新增注入记录（知识库、版本、编号、字符数）
- error：超限、失效条目（阻塞确认）、调用失败
- empty：项目下没有可用知识库 →「该项目还没有知识库」+「去导入」；本次调用仅使用提示文本
- over-limit：显示分段字数与超出量，禁用「发起调用」

### 失效条目阻塞确认对话框（US-014）

**Purpose**: 在发起外部请求前，把「本次实际不会注入哪些编号」明确交给用户确认。

**Layout**:

```
|                       [取消] [继续调用（2 条）]   |
+--------------------------------------------------+
```

**Key Elements**:
| Element | Type | Behavior |
|---------|------|----------|

## 关键交互约定

### 导入校验与文案（就近展示）

| 场景 | 触发 | 文案 |
|------|------|------|
| 文件类型 | 不在白名单 | 「不支持 {ext}；知识库仅允许 .json / .md / .markdown」 |
| 缺少索引 | 未选择 `index.json` | 「缺少 index.json：知识库必须包含 index.json」 |
| `index.json` 大小 | >20MB | 「index.json 超过 20MB 上限（当前 {size}）」 |
| 其他文件大小 | >10MB | 「{name} 超过 10MB 上限」 |
| 文件数量 | >50 个 | 「单次最多导入 50 个文件（当前 {n} 个）」 |
| 合计大小 | >100MB | 「单个知识库合计不能超过 100MB（当前 {size}）」 |
| `index.json` 结构 | 非法 JSON / 缺版本标识 / 缺条目集合 / 条目集合为空 | 「index.json 结构不合法：需要版本标识与条目集合，且条目不能为空」 |
| 无可导入条目 | 所有条目被跳过 | 「没有可导入的条目，导入已回滚，未创建知识库」 |
| 同名重导 | 同项目同名 | 不报错，提示「同名重新导入：已生成 v{N}，旧版本只读保留」 |
| 注入预算 | 提示 + 注入 >200,000 | 「超出上限：提示 {p} 字符 + 注入 {i} 字符 = 合计 {t} / 200,000 字符，超出 {n} 字符。不会截断，请取消勾选或缩短提示」 |
| 失效条目 | 已删除 / 被取代 / 不存在 | 阻塞对话框列出「{编号} {标题}（{原因}）」 |

### 字符预算与注入口径
- 常量：200,000 字符（Unicode 码点），由 core 的 `AW_PROMPT_MAX_CHARS` 单点定义。
- 展示：`已选 N 条 · 注入 X 字符（含编号与标题）· 提示 Y 字符`、`合计 Z / 200,000`；X 按完整注入块统计（编号、标题、正文或摘要、知识库名与生成时间），与 core 对最终 prompt 的校验同口径（UXAMB-001 已确认）。
- 阈值：Z > 90% warning；Z > 200,000 destructive + 禁用「发起调用」；不截断、不自动取消勾选。
- 提示为空时「发起调用」禁用并提示「请填写提示」；提示非空但无勾选时允许仅用提示调用（预算照常显示）。

### 失效条目阻塞确认（AC-014-4）
- 触发：点击「发起调用」后、发起外部请求前校验所选条目。
- 剔除原因：知识库已删除 / 已被新版本取代 / 条目不存在。
- 对话框必须列出**全部**被剔除编号，不可折叠；确认按钮文案带有效条数。
- 取消：不发起调用、不产生 AiCallRecord；弹窗关闭；失效条目自动取消勾选并标「不可用」；保留提示与其余勾选。
- 确认：用剩余有效条目发起；时间线记录实际注入的知识库、版本、编号列表与字符数，并记录「已剔除 N 个失效编号」。
- 若剔除后有效条目为 0：确认按钮改为「仅用提示继续」并说明本次不注入知识库；取消仍不发起。

### 版本与新鲜度
- 浏览默认最新版；旧版本下拉标「只读」；选旧版本时 banner 说明并提供「查看最新版」。
- 新鲜度：有字段且 ≤30 天显示「N 天前」；>30 天「可能过期」（warning）；缺字段「未知」（中性）。不推测、不克隆仓库、不解析代码。
- 版本冲突：同项目同编号摘要不同 → 「版本冲突」；详情卡列出来源（知识库名 + 版本 + 生成时间）；注入选择器只显示徽标，不展开来源。
- 所有提示只提示不阻断；唯一阻断来自失效条目（AC-014-4）。

### 通用状态约定
- **加载**：首屏骨架屏；超过 400ms 才显示；按钮内联 loading 并禁用重复提交。
- **成功**：toast 2.4s；导入 / 删除后列表顶部 banner 保留本轮结果。
- **错误**：就近展示并保留输入；列出可执行的下一步（移除文件、换文件、缩短提示、取消勾选）。
- **空态**：每个列表都有空态；知识库为空、条目无匹配、项目无知识库、会话无可用知识库分别给说明与 CTA。
- **只读**：调用进行中，提示与选择器只读；知识库本身永远只读，不提供编辑入口。
- **不可信内容**：正文、摘要、字段值按纯文本渲染（默认转义），不渲染 HTML；不进入应用日志与错误响应。

### 键盘与可访问性
- Tab 顺序：侧边栏 → 顶栏 → 筛选区 → 内容区；对话框打开后焦点进入标题，Esc 关闭并把焦点还给触发按钮。
- 对话框使用 `role="dialog"` / `role="alertdialog"` + `aria-modal="true"`；失效确认使用 `alertdialog`。
- 状态徽标同时用文字与颜色；复选框行整行可点击并带 `aria-describedby` 指向徽标说明。
- 焦点环 2px `--color-ring`；尊重 `prefers-reduced-motion`。
- 正文与背景对比度 Light / Dark 均 ≥ 4.5:1（token 沿用 core 实测值）。

### 响应式
- ≥1024px：侧边栏常驻；浏览页「列表 + 详情」可在宽屏双栏，窄屏改为进入详情页。
- 768–1023px：侧边栏图标 + 文本；筛选区换行；注入选择器与提示上下堆叠。
- <768px：侧边栏抽屉；表格转卡片；按钮最小 44×44px；对话框全宽（留 16px 边距）。

### 交互取舍

| # | 取舍 | 决定 | 理由 |
|---|------|------|------|
| 1 | 知识库入口放哪里 | 「基座管理」分组，独立于六个业务入口 | 知识库是会话调用依据的项目资产，不是独立业务能力（AMB-017） |
| 2 | 导入与会话上传是否共用面板 | 不共用：独立导入页与独立校验规则 | 两套白名单与上限不同（AMB-007 vs AMB-014） |
| 3 | 列表是否展开旧版本 | 只展示最新版本一行 + 「另有 N 个旧版本（只读）」 | 浏览默认最新版；旧版本通过版本切换查看 |
| 4 | 冲突与过期是否用红色阻断色 | 用 warning / 中性徽标，不用 destructive | AMB-016「只提示不阻止」；红色会被误读为不可用 |
| 5 | 版本冲突展示位置 | 列表行徽标 + 详情冲突卡（来源列表），注入选择器只显示徽标 | 选择前看到风险，详情可追溯来源 |
| 6 | 注入选择器形态 | 会话调用面板内嵌复选框列表，不弹窗 | 需要与提示正文同屏看预算（AC-014-1） |
| 7 | 删除入口 | 只在知识库列表行提供，浏览页不提供 | 删除影响整个版本链，从列表发起能看到项目与版本上下文 |
| 8 | 导入失败后已选文件是否保留 | 保留，允许移除 / 替换后重试；取消才丢弃 | 用户可逐项修正，避免重新选文件 |
| 9 | 旧版本只读标记的层级 | 知识库版本级标注「已被新版本取代」，同版本条目继承 | 取代发生在版本层（AMB-017） |
| 10 | 注入选择在会话内是否跨调用保留 | 保留在当前会话内；刷新或重新进入会话重置；不持久化 | 一次调用后常调整提示重试；重新进入时仍需即时校验，避免隐式上下文 |
| 11 | 失效条目如何提示 | 阻塞式对话框（列编号）替代内联提示 | AC-014-4 要求不静默降级；内联提示可能被忽略 |
| 12 | 失效确认的取消语义 | 不发起、不产生记录；保留提示与勾选，失效项自动取消勾选 | 取消是「这单不发了」，不是「清空我的输入」 |
| 13 | 项目上下文关联区块的归属 | 本 spec 提供组件与线框，core 页面只加挂载位 | 满足 AC-012-6，同时不改 core 既有布局（见 UXAMB-004） |
| 14 | 条目详情是否单独路由 | 是（`/knowledge-bases/:kbId/entries/:code`），可分享与回退 | 注入前核对与回看需要稳定链接；返回保留筛选 |
| 15 | 是否需要「导入报告」回看入口 | 本期不做 | AC 只要求导入结束展示；后续需要再补 |

#### UXAMB-001

- 歧义描述：字符预算里的「注入字符数」统计口径未定——只统计条目正文 / 摘要（AMB-015 字面），还是统计最终注入块的全部字符（编号、标题、正文或摘要、知识库名与生成时间）。若 UI 只按正文计，用户看到的合计可能小于 core 对最终 prompt 的校验值，导致「显示未超限但调用被拒」。
