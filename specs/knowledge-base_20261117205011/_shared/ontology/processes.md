# Processes

### BP-C5 知识库导入
- **对应图谱**：未覆盖
- **触发条件**：用户在项目下上传知识库文件（`index.json` + 可选 `.md`）
- **操作的对象**：ENT-C10（创建知识库并关联项目）、ENT-C11（按编号建立条目索引）
- **来源 spec**：knowledge-base_20261117205011

### BP-C6 知识库条目浏览与检索
- **对应图谱**：未覆盖
- **触发条件**：用户打开知识库浏览页，按项目 / 知识库 / 类型筛选或输入编号、关键词检索
- **操作的对象**：ENT-C11（只读查询条目详情、一跳邻居与新鲜度）
- **来源 spec**：knowledge-base_20261117205011

### BP-C7 知识库条目注入调用
- **对应图谱**：未覆盖
- **触发条件**：用户在会话内勾选知识库条目并发起调用
- **操作的对象**：ENT-C11（读取条目正文并拼接注入块）；注入快照写入会话事件与调用记录（归 workbench-core）
- **来源 spec**：knowledge-base_20261117205011

### BP-C8 知识库删除
- **对应图谱**：未覆盖
- **触发条件**：用户二次确认删除知识库
- **操作的对象**：ENT-C10、ENT-C11（级联删除条目索引与已存文件，移除项目关联；历史会话不改）
- **来源 spec**：knowledge-base_20261117205011
