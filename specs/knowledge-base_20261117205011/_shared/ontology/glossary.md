# Glossary

### TERM-C10 知识库
- **对应图谱**：未覆盖
- **定义**：由外部本体工具（`ontology-builder-native` + `ontology-consumption`）产出的、按编号组织的业务知识文件集合（`index.json` + `.md`），由用户上传到某个项目，供浏览与按编号注入；工作台只读，不在线编辑。
- **避免的叫法**：知识图谱、向量库、文档库
- **来源 spec**：knowledge-base_20261117205011

### TERM-C11 知识库条目
- **对应图谱**：未覆盖
- **定义**：知识库中按编号（如 `ENT-123`、`BR-045`）标识的一条业务知识，含类型、标题、字段、表、代码路径、一跳邻居与新鲜度；编号是浏览、检索与注入的稳定引用键。
- **避免的叫法**：节点、记录、文档片段
- **来源 spec**：knowledge-base_20261117205011

### TERM-C12 知识注入
- **对应图谱**：未覆盖
- **定义**：会话发起调用时，把用户勾选的若干知识库条目按「编号 + 标题 + 正文（缺失用摘要）」拼入提示上下文；注入正文与用户提示正文合计受 200,000 字符上限约束，注入的知识库与编号记入 AiCallRecord 与 SessionEvent。
- **避免的叫法**：RAG、检索增强、前置知识
- **来源 spec**：knowledge-base_20261117205011

### TERM-C13 知识库版本
- **对应图谱**：未覆盖
- **定义**：同一项目下同名知识库的一次导入快照；首次导入为 v1，同名重新导入生成 v(max+1)，旧版本只读保留，浏览与注入默认使用当前版本。
- **避免的叫法**：副本、备份、分支
- **来源 spec**：knowledge-base_20261117205011
