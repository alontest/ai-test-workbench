- 来源：`specs/ai-test-workbench_20261117184149/interaction-design/`（2026-11-17 收窄前版本）
- 去向：`specs/knowledge-base_20261117205011/`（US-012 ~ US-016 / 原 AC-UX-19 ~ AC-UX-26）
- 用途：知识库 spec 的交互设计阶段可直接照此落地；壳、token 与登录态复用 workbench-core，不要另起一套。
- 用户已定：知识库复用本 spec 的 AppShell、设计 token 与登录态；入口放侧边栏（独立入口），会话面板内做注入。

## 1. 可复用的壳、登录态与组件

### 1.1 AppShell 布局
- 固定左侧边栏 `248px` + 顶栏 `64px` + 内容区（最大宽度 `1280px`）。
- 侧边栏分三组：
  - 工作台：首页、分析会话
  - 入口：六个业务入口（本 spec 不新增业务入口）
  - 基座管理：项目上下文、AI 提供商与模型、调用记录、**知识库（本 spec 追加）**
- 顶栏：页面标题 + 副标题；右侧主题开关、「管理员 ▾」用户菜单（单用户 · 口令登录 / 退出登录）。demo 专用的 UI 状态切换与「模拟会话过期」不进入产品。
- ≤768px 侧边栏收起为抽屉（汉堡按钮）；768–1023px 收窄为图标 + 文本；表格转卡片；按钮最小 44×44px。
- 路由：`/knowledge-bases`（列表）、`/knowledge-bases/import`（导入）、`/knowledge-bases/:kbId`（浏览与检索）、`/knowledge-bases/:kbId/entries/:code`（条目详情）。全部与现有工作台路由一样受 `AuthGate` 保护。

### 1.2 登录态（直接复用，不重做）
- `AuthGate`：未认证页面重定向 `/login?next=<原路径>`，接口 401；`next` 只接受站内路径（拒绝绝对 URL 与 `//`）；登录成功回跳原目标；未认证不渲染侧边栏与任何业务 DOM。
- `LoginPage`：独立卡片，`type=password`、`autocomplete=current-password`、回车提交；提交中「登录中…」并禁用；错误统一「口令错误，请重试。」；同一来源连续失败 5 次锁定 5 分钟并显示 `mm:ss` 倒计时，期间禁用输入与按钮；支持 Light / Dark；不提供注册、找回口令、记住我、显示口令。
- 会话过期：空闲 8 小时后下一次请求 401 → 静默跳登录页并提示「会话已过期，请重新登录。已填写但未提交的内容已保留，重新登录后会恢复。」；未提交草稿只存内存，刷新 / 关闭标签页丢失；显式登出立即吊销令牌、不二次确认、丢弃草稿，提示「已退出登录。」。
- `UserMenu`：顶栏「管理员 ▾」，显示「单用户 · 口令登录」，提供「退出登录」；Esc 关闭、点击外部收起、`aria-expanded`。

## 2. 入口与信息架构（已确认决策原文）

- 知识库入口放在侧边栏「基座管理」分组（与项目上下文、AI 提供商、调用记录同级），路由 `/knowledge-bases`。
- 知识库归属项目，同一项目下名称唯一；同名重新导入生成新版本，旧版本只读保留。
- 页面分三类：列表页（导入入口、版本、删除）、导入页（多文件上传 + 逐项校验 + 导入报告）、浏览 / 详情页（类型分栏 + 编号检索 + 条目详情）；勾选注入放在会话详情的「发起调用」面板内，与提示正文共用 200,000 字符预算。
- 理由原文：知识库是「外部工具生成、工作台只读引用」的项目级资产（AMB-017 归属项目、AMB-014 上传边界、AMB-015 注入预算、AMB-016 新鲜度只提示、AMB-018 删除语义）；导入与浏览必须是两条独立路径：导入面向文件校验，浏览面向按编号查业务概念。
- 备选方案（未采用）：放进「项目上下文」页签；做成第七个业务入口；注入选择器做成独立弹窗。
- 权衡：列表在「基座管理」内多一层导航；浏览页信息密度高，小屏上下堆叠；旧版本与冲突提示只出现在浏览 / 详情与注入预览，不在列表页做主视觉，避免把「只提示」做成「阻断」。
- 边界：知识库只读，不在线编辑条目；删除只影响知识库、条目与文件，历史会话与调用记录保留并在编号旁标注「知识库已删除」。

## 3. 页面线框与关键元素

### 3.1 知识库列表页（US-012 / US-015 / US-016）

```
+----------------------+-------------------------------------------------------+
| (sidebar)            | 知识库                              [+ 导入知识库]    |
|  基座管理             +-------------------------------------------------------+
|  项目上下文           | 项目 [全部 ▼]   共 2 个知识库                          |
|  AI 提供商与模型      | +---------------------------------------------------+ |
|  调用记录             | | 名称             项目   版本  生成时间   条目 状态 操作| |
|  知识库 ←             | | 支付台业务知识库 支付台 v3    11-17 09:12 42  已就绪 [浏览][删除]| |
|                      | |   另有 1 个旧版本（只读）                        | |
|                      | | 风控规则知识库   风控台 v1    未知        18  已就绪 [浏览][删除]| |
|                      | +---------------------------------------------------+ |
|                      | 只读导入：工作台不修改上传文件，也不在线编辑条目；       |
|                      | 同名重新导入会生成新版本，旧版本只读保留。              |
+----------------------+-------------------------------------------------------+
```

| Element | Type | Behavior |
|---------|------|----------|
| 项目筛选 | Select | 全部项目 / 单个项目；变更即过滤，默认全部 |
| 导入知识库 | Primary button | 跳转 `/knowledge-bases/import`；若未选具体项目，导入页要求先选项目 |
| 知识库行 | Table row | 列：名称、项目、最新版本、生成时间（缺失显示「未知」）、条目数、状态（已就绪）、操作 |
| 旧版本提示 | Inline text | 存在旧版本时显示「另有 N 个旧版本（只读）」，不展开旧版本行 |
| 浏览 | Row button | 进入 `/knowledge-bases/:kbId`，默认最新版本 |
| 删除 | Row button (danger) | 打开删除确认对话框，列明级联范围；无撤销 |
| 只读说明 | Static text | 页脚固定说明：只读导入、同名生成新版本、旧版只读 |

States：default（筛选 + 表）/ loading（标题 + 4 行骨架）/ success（导入或删除后回列表，顶部 banner：「导入成功 · 新增 1 个知识库」「知识库已删除」）/ error（可重试，保留项目筛选）/ empty（「还没有知识库」+「导入知识库」+ 说明「先在本地用 ontology-builder-native / ontology-consumption 生成知识库文件」）。

### 3.2 删除知识库确认对话框（US-016）

```
+--------------------------------------------------+
| 删除知识库？                                [×]   |
| 删除后不可恢复。历史会话与调用记录不受影响，       |
| 相关编号将标注「知识库已删除」。将同时删除：       |
|  • 知识库「支付台业务知识库」及其全部版本（v3、v2）|
|  • 条目索引（该知识库全部条目）                   |
|  • 已存文件（index.json 与 .md 附件）             |
|  • 项目与该知识库的关联                           |
|                          [取消]  [删除]           |
+--------------------------------------------------+
```

行为：仅从列表行发起；确认后列表与浏览页移除、其他知识库不受影响；历史会话与调用记录中的相关编号标「知识库已删除」；无撤销、无自动过期清理。

States：default / confirm-loading（「删除中…」并禁用按钮）/ error（失败提示并保留对话框，可重试）。

| Element | Type | Behavior |
|---------|------|----------|
| 项目选择 | Select | 必选；无项目时禁用提交并给「新建项目」链接（AC-012-1 归属项目） |
| 文件选择区 | Dropzone + file input | 多选，`accept=".json,.md,.markdown"`；拖拽或点击 |
| 校验规则说明 | Static text | 白名单、必须含 `index.json`、20MB / 10MB / 50 个 / 100MB |
| 校验结果列表 | List | 每文件一行：文件名、大小、结果（通过 / 具体原因）；不合规标红可移除；整体错误（缺少 `index.json`、数量或合计超限）显示在列表上方 |
| 提交导入 | Primary button | 有错误或无文件时禁用；提交中「校验中…」；服务端结构校验失败时不创建知识库并提示最小结构（版本标识 + 条目集合） |
| 导入报告 | Result card | 成功：知识库名 + 版本 + 已导入条目数 + 跳过条目（行号 + 原因）；同名导入提示「已生成新版本 vN，旧版本只读保留」 |
| 取消 | Secondary button | 返回列表，丢弃已选文件 |

States：default（空选择区 + 规则）/ loading（「校验中…」+ 列表只读）/ success（报告 +「查看知识库」）/ error（类型不支持 / 缺少 `index.json` / 超出大小 / 超出数量 / 合计超限 / 非法 JSON / 缺版本标识 / 缺条目集合 / 条目集合为空 → 明确原因，不写入任何文件、不创建知识库）/ empty（未选择文件 → 提交禁用，提示「请选择至少包含 index.json 的文件」）。

导入失败后已选文件保留，允许移除 / 替换后重试；只有「取消」才丢弃。

| 最新版跳转 | Text link | 当前版本被取代时提供「查看最新版本」 |
| 返回 | Text link | 回到浏览页，保留筛选与检索词 |

States：default / loading（骨架）/ success / error（条目不存在或已随知识库删除 → 说明 + 返回浏览；知识库已删除时标注「知识库已删除」）/ empty（缺少所有明细字段 → 只展示编号、标题、摘要与「字段信息缺失」，不渲染空表格）。

### 3.6 会话调用面板 · 知识库注入（US-014 / US-015）

```
+----------------------------------------------+
| 发起调用                                     |
| 提示（必填）                                 |
| [请分析以下登录报错的可能原因_____________]   |
| 知识库注入（按编号勾选）                     |
|  [✓] TERM-001 支付单        术语 [可能过期]  |
|  [✓] ENT-002  支付订单      实体 [可能过期]  |
|  [ ] BR-003   重复支付拦截  规则 [正文缺失]  |
|  [ ] API-006  创建支付接口  接口 [版本冲突]  |
| 已选 2 条 · 注入 1,204 字符 · 提示 19 字符   |
| 合计 1,223 / 200,000 字符                    |
| [!] 超出上限：提示 200,001 + 注入 1,204      |
|     = 201,205 / 200,000，超出 1,205 字符。   |
|     不会截断，请取消勾选或缩短提示。          |
|                         [ 发起调用 ]         |
+----------------------------------------------+
```

| Element | Type | Behavior |
|---------|------|----------|
| 条目选择器 | Checkbox list | 只列当前会话项目的最新版本知识库条目；每行：编号 + 标题 + 类型 + 新鲜度 / 冲突 / 正文缺失徽标；已删除知识库的条目不再出现 |
| 已选摘要 | Inline text | 「已选 N 条 · 注入 X 字符 · 提示 Y 字符 · 合计 Z / 200,000 字符」；勾选、取消与输入提示时实时更新 |
| 超限错误 | Error block | 合计超过 200,000 时显示提示 / 注入 / 合计 / 上限与超出量，并明确「不会截断」；「发起调用」禁用 |
| 失效条目 | Error block | 所选条目已删除 / 被取代 / 不存在时，列出具体编号并阻止这些条目，其余有效条目不阻止 |
| 发起调用 | Primary button | 提示非空且合计未超限时可用；调用中「调用中… 最长 120s」 |
| 注入结果 | Timeline event | 调用事件展示知识库名 + 版本 + 编号列表 + 字符数（不记录正文）；知识库已删除时编号旁显示「知识库已删除」 |

States：default（提示 + 选择器 + 预算条）/ loading（调用中，选择器与提示只读）/ success（时间线新增注入记录）/ error（超限、失效条目、调用失败）/ empty（项目下没有可用知识库 → 「该项目还没有知识库」+「去导入」；本次调用仅使用提示文本）。

注入选择在当前会话内保留，切换页面不丢失；刷新或重新进入会话重置；不持久化到服务端。注入块统一为「编号 + 标题 + 正文（缺失用摘要）+ 知识库名与生成时间」；AiCallRecord 与 SessionEvent 记录知识库、编号列表与字符数，不记录正文；知识库正文与注入内容不进入应用日志与错误响应。

### 3.7 项目上下文页的关联知识库（US-012 / AC-012-6）
- 选中项目下展示关联知识库摘要：名称、版本、条目数、生成时间或「未知」，最多 3 条 + 「查看全部」，跳转 `/knowledge-bases?project=<id>`。
- 无知识库时显示空态「该项目还没有知识库」+「导入知识库」。

## 5. 校验与错误文案（原样迁移）

| 场景 | 触发 | 文案 |
|------|------|------|
| 知识库文件类型 | 不在白名单 | 「不支持 {ext}；知识库仅允许 .json / .md / .markdown」 |
| 知识库缺少索引 | 未选择 `index.json` | 「缺少 index.json：知识库必须包含 index.json」 |
| `index.json` 大小 | >20MB | 「index.json 超过 20MB 上限（当前 {size}）」 |
| 知识库其他文件大小 | >10MB | 「{name} 超过 10MB 上限」 |
| 知识库文件数量 | >50 个 | 「单次最多导入 50 个文件（当前 {n} 个）」 |
| 知识库合计大小 | >100MB | 「单个知识库合计不能超过 100MB（当前 {size}）」 |
| `index.json` 结构 | 非法 JSON / 缺版本标识 / 缺条目集合 / 条目集合为空 | 「index.json 结构不合法：需要版本标识与条目集合，且条目不能为空」 |
| 知识库无可导入条目 | 所有条目都被跳过 | 「没有可导入的条目，导入已回滚，未创建知识库」 |
| 知识库名称 | 同项目重名 | 不报错：生成新版本，提示「同名重新导入：已生成 v{N}，旧版本只读保留」 |

通用：加载用骨架屏（超过 400ms 才显示，避免闪烁）；按钮内联 loading 并禁用重复提交；成功 toast 2.4s；错误就近展示并保留已填内容；空态至少一句说明 + 可选 CTA；破坏性操作用确认对话框、按钮为动词、无撤销；密钥与正文不进日志与错误响应。

## 6. 交互取舍（原 10 条，原文迁移）

| # | 取舍 | 决定 | 理由 |
|---|------|------|------|
| 1 | 知识库入口放哪里 | 「基座管理」分组，独立于六个业务入口 | 知识库是会话调用依据的项目资产，不是独立业务能力（AMB-017 归属项目；原则 1 入口清晰） |
| 2 | 导入与会话上传是否共用面板 | 不共用：独立导入页与独立校验规则 | 两套白名单与上限不同（AMB-007 会话上传 vs AMB-014 知识库）；复用会误导用户 |
| 3 | 列表是否展开旧版本 | 每个知识库只展示最新版本一行 + 「另有 N 个旧版本（只读）」 | 浏览默认最新版（AMB-017）；旧版本通过浏览页版本切换查看，避免列表被历史版本淹没 |
| 4 | 冲突与过期是否用红色阻断色 | 用 warning / 中性徽标，不用 destructive；只提示不阻止 | AMB-016 明确「只提示不阻止」；红色会让用户误以为不可用 |
| 5 | 版本冲突展示位置 | 列表行徽标 + 详情冲突卡（来源列表），注入选择器只显示徽标 | 用户在选择前需要看到风险，详情页需要可追溯来源（知识库名 + 版本 + 生成时间） |
| 6 | 注入选择器形态 | 会话调用面板内嵌复选框列表，不弹窗 | 需要与提示正文同屏看字符预算（AC-014-1）；弹窗会遮挡预算与提示 |
| 7 | 删除入口 | 只在知识库列表行提供，浏览页不提供 | 删除影响整个知识库版本链；从列表发起能先看到项目与版本上下文（风险可控） |
| 8 | 导入失败后已选文件是否保留 | 保留，允许移除/替换后重试；取消才丢弃 | 用户可逐项修正，避免重新选文件（输入明确） |
| 9 | 旧版本只读标记的层级 | 知识库版本（不是单条目）标注「已被新版本取代」；条目详情同版本所有条目继承该标记 | 取代发生在版本层（AMB-017）；条目级只额外标注冲突与新鲜度 |
| 10 | 注入选择在会话内是否跨调用保留 | 保留在当前会话的调用面板内，切换页面不丢失；刷新或重新进入会话重置 | 一次调用后用户常会调整提示重试；不持久化到服务端，避免隐式上下文（AC-014-4 失效条目仍需即时校验） |

原 open-questions 的 6 条默认（入口位置、导入面板独立、旧版本折叠、冲突只提示、注入选择器形态、注入选择保留范围）与上表一致，已随本 spec 迁出。

## 8. 原验收标准（AC-UX-19 ~ AC-UX-26，原文迁移）

- AC-UX-19：侧边栏「基座管理」提供「知识库」入口（与项目上下文 / AI 提供商与模型 / 调用记录同级），并为 US-012 ~ US-016 提供线框图、流程图与 demo 页面。
- AC-UX-20：仅接受 `.json` / `.md` / `.markdown` 且要求包含 `index.json`，逐文件展示校验结果与原因（类型 / 单文件大小 / 数量 / 合计）；不合规时禁用提交并逐项说明，不写入任何文件、不创建知识库。
- AC-UX-21：导入完成展示报告：知识库名与版本、已导入条目数、被跳过条目的行号与原因；同名重新导入提示生成新版本、旧版本只读；无任何可导入条目时整体失败并说明回滚。
- AC-UX-22：浏览支持按项目、知识库、类型筛选与编号前缀 / 完整编号 / 关键词检索，默认最新版本，无匹配空态；详情展示字段、表、代码路径、一跳邻居、来源文件与新鲜度，正文缺失时展示摘要并标注「正文缺失」。
- AC-UX-23：同项目同编号摘要冲突、新鲜度超过 30 天或字段缺失时分别标注「版本冲突」（列出来源）、「可能过期」与「未知」；被取代版本标注「已被新版本取代」并提供跳转最新版；只提示不阻止注入。
- AC-UX-24：勾选条目时实时展示已选条目数、注入字符数、提示字符数与合计 / 200,000；超限展示分段字数与超出量、说明不截断并禁用「发起调用」，不静默截断。
- AC-UX-25：调用完成且使用注入时，时间线与调用记录展示知识库名、版本、编号列表与字符数，不展示正文；所选条目失效时在发起外部请求前提示具体编号并阻止使用。
- AC-UX-26：删除知识库先弹确认，列明级联范围（知识库及其版本、条目索引、已存文件、项目关联）并说明历史会话与调用记录不受影响；确认后浏览页不再出现该知识库，历史会话中的相关编号标注「知识库已删除」。

原 demo 验证记录：Playwright（系统 Chrome headless，1440×1000）43 项断言全部通过、页面脚本错误 0，覆盖导入校验失败、导入成功、浏览与检索、条目详情与邻居、版本冲突、可能过期、未知、正文缺失、勾选注入与字符计数、超限拒绝、删除确认与历史标注、明暗主题。
